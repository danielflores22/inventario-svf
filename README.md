# Toma de inventario – ADMIFICONT

Herramienta de conteo de inventario instalable en el celular (funciona sin internet).
Los datos de inventario no se suben a este repositorio: se cargan en cada equipo y quedan guardados solo en ese navegador.

Para usarla: abre la página publicada en Chrome (Android) o Safari (iPhone) y elige "Agregar a pantalla de inicio".
